      Publish to the site

      Saves data/store.json and any newly uploaded photos to your GitHub repo in a single commit. Vercel redeploys automatically, and the site updates in about a minute. Use a fine-grained token limited to this one repository with Contents: Read and write.

      Backup

      Download the data file to publish manually (replace data/store.json in the project and deploy; uploaded photos are only saved by Publish), or import a file you saved earlier.
